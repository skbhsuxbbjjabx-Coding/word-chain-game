# ⚡ 끝말잇기 마스터 AI (WordChain Master AI)

> **네이버 국어사전 & 국립국어원 표준국어대사전 52만+ 전수 어휘 기반**  
> **게임 이론(Game Theory) 기반 최적·최선·최강·최상 단어 추천 & AI 실시간 대결 시스템**

---

## 🌟 프로젝트 개요

사용자가 앞글자 또는 단어를 입력하면, 끝말잇기 그래프 이론에 입각하여 **즉시 승리하는 한방 단어**, **상대의 패를 묶는 외통수 단어**, **안전한 방어 단어**, **품격 있는 장기전 단어**를 초고속(1ms)으로 분석하여 제공합니다.

또한 임의로 단어를 지어내는 것이 아닌, **약 52만 개에 달하는 네이버 국어사전 및 표준국어대사전의 실제 등록 어휘 전수 데이터베이스**를 탑재하고, 실시간 네이버 국어사전 API 연동을 통해 표제어, 품사, 공식 뜻풀이를 100% 매칭하여 보여줍니다.

---

## 🚀 주요 기능

### 1. 💬 AI 전략 참모 & 실시간 단어 추천 챗 (AI Word Advisor)
- 사용자가 앞글자(예: `'기'`) 또는 단어(예: `'비행기'`)를 입력하면 4대 전략 카드 즉시 도출:
  - 💥 **최강 (한방 / Instant Win)**: 상대의 다음 가능한 어휘 수가 정확히 0개(Out-degree = 0)인 필승 킬링 단어
  - ⚔️ **최적 (외통수 / Deadly Trap)**: 상대의 다음 선택지를 1~3개로 극도로 제한하여 다음 턴에 100% 카운터로 승리하는 함정 공격 단어
  - 🛡️ **최선 (안전 방어 / Safe Defense)**: 까다로운 글자를 회피하고 안전하게 전세를 유지하는 방어 단어
  - 🌟 **최상 (명품 랠리 / Grand Mastery)**: 풍부한 후속 경로를 지닌 품격 있는 정통 한국어 명사
  - 🔄 **두음법칙 전용 단어**: 국립국어원 한글 맞춤법 제10~12항 두음법칙을 완벽 적용한 역전 단어
- **단어 복사(Clipboard Copy)** 및 **배틀 즉시 투입** 원클릭 지원
- 네이버 국어사전 공식 실시간 뜻풀이 및 네이버 사전 바로가기 링크 제공

### 2. ⚔️ 실시간 끝말잇기 배틀 (PvE Battle Arena)
- 마스터 AI와 직접 턴을 주고받는 인터랙티브 대결 모드
- 3단계 난이도:
  - 💀 **알파고(자비없음)**: 1~2턴 안에 한방 단어로 즉시 플레이어를 격파
  - ⚡ **고수(마스터)**: 강력한 외통수와 공격 단어를 구사하는 전략적 모드
  - 🌱 **트레이닝**: 긴 랠리를 연습할 수 있는 안전한 대결 모드
- 실시간 네이버 국어사전 52만 단어 검증:
  - 미등재 단어, 중복 단어, 잘못된 연결, 두음법칙 자동 판정
- 콤보 카운터, 체인 히스토리, Web Audio API 효과음(타격음, 승리 팡파레)

### 3. 🔍 네이버 국어사전 52만 전수 분석실 (Dictionary Inspector)
- 어떤 단어나 글자든 네이버 국어사전 실시간 검색
- 표제어, 품사, 네이버 국어사전 공인 뜻풀이
- **끝말잇기 전투력 지표** 분석:
  - 끝말잇기 공격력 / 위력 지수
  - 해당 글자의 후속 단어 개수(Out-degree)
  - 두음법칙 변환 분기표

### 4. 💀 절대 한방 단어 렉시콘 (Killing Words Codex)
- 끝말잇기에서 상대가 절대 이을 수 없는 166개 한방 음절(`륨`, `늄`, `릇`, `늧`, `녘`, `켓`, `슨`, `븨` 등) 완벽 분류
- 글자별 대표 필승 단어 모음 및 원클릭 복사

## 🛠️ 기술 아키텍처

- **백엔드**: Node.js 내장 고속 서버 (`server.js`)
  - 420,256개 유효 한국어 단어 메모리 인덱싱 (로드 시간: ~0.8초, 메모리: ~70MB)
  - 실시간 네이버 국어사전 API 프록시 & LRU 캐싱
  - 유향 그래프 기반 Out-degree 및 Minimax 탐색 엔진
  - 국립국어원 표준 두음법칙 양방향 변환 알고리즘
- **프론트엔드**:
  - 네온 사이버 HUD 다크 테마 디자인 (`style.css`)
  - 반응형 2열 레이아웃 (어드바이저 챗 & 워크스페이스)
  - Web Audio API 무지연(Zero-latency) 신디사이저 사운드 시스템 (`sound.js`)
  - 실시간 SPA 인터랙션 및 상태 관리 (`app.js`)

## 🏃 실행 방법

### 방법 1: 런처 더블 클릭
`start.bat` 파일을 더블 클릭하면 자동으로 서버가 실행되고 브라우저가 열립니다.

### 방법 2: 명령줄 실행
```bash
node server.js
```
실행 후 웹 브라우저에서 `http://127.0.0.1:3000`에 접속합니다.
