# 끝잇

깔끔하고 편안한 분위기의 온라인 끝말잇기 게임 프로토타입입니다.

## 현재 포함된 기능

- 닉네임 저장이 가능한 로비
- 2인, 3인, 4인 빠른 매칭 흐름
- 친구 초대 코드 생성과 코드 입력 화면
- 채팅형 게임 화면과 20초 턴 타이머
- 사전 등록 단어 검증, 중복 단어 차단
- 첫 턴 한방단어 차단
- 쉬움/보통/어려움으로 확장 가능한 AI 선택 로직
- 어려움 AI의 카운터 후보 수 기반 단어 선택
- 사전 뜻을 함께 보여주는 팩트체크 UI
- 소리, 닉네임, 도움말, 게임 룰, 방 코드 복사

## 실행

```bash
npm run dev
```

실행 후 `http://127.0.0.1:4173`을 엽니다.

현재 버전은 바로 플레이할 수 있는 프론트엔드 프로토타입입니다. 실제 여러 기기 간 온라인 매칭을 위해서는 다음 단계에서 WebSocket 서버와 공식 사전 데이터 동기화를 붙이면 됩니다. `WORD_BANK`와 `selectAIWord`는 그 확장을 고려해 분리해 두었습니다.
