# ⚡ 끝말잇기 마스터 AI (WordChain Master AI)

> **끄글(Kkeugl) 548,502개 공인 단어 전수 탑재 & 네이버 국어사전 100% 실시간 연동**  
> **게임 이론(Game Theory) & Minimax 심층 수읽기 기반 5단계 의사결정 인공지능 엔진**

---

## 🌟 프로젝트 개요

사용자가 앞글자 또는 단어를 입력하면, 끝말잇기 그래프 이론에 입각하여 **즉시 승리 한방 단어**, **한방 유도 외통수 단어**, **치명적 압박 단어**, **안전 방어 단어**, **위기 탈출 차선책 단어**를 초고속(1ms)으로 분석하여 제공합니다.

또한 임의로 단어를 걸러내거나 지어내는 것이 아닌, **끄글(Kkeugl) 공인 548,502개 전수 단어 데이터베이스**를 탑재하고, 실시간 네이버 국어사전 공식 API3 연동을 통해 표제어, 품사, 구체적 공식 뜻풀이를 100% 매칭하여 보여줍니다.

---

## 🚀 주요 기능

### 1. 💬 AI 전략 참모 & AI브리핑 (5단계 의사결정 수읽기 엔진)
- **📝 상대방 단어 적기 모드 (자동 턴 인식)**:
  - **앞글자만 1자 입력** (예: `'기'`): **[내 턴]**으로 자동 인식하여 5단계 우선순위에 따른 필승 수 브리핑
  - **풀네임 2자 이상 단어 입력** (예: `'다다르다'`): **[상대 턴]**으로 자동 인식하여 상대 단어 사전 검증 및 공수 양면 전략, 한방 역공 덫 즉시 브리핑
- **🌊 흐름 모드**: 실시간 대결 중 나온 단어들을 자동 누적하여 중복 사용을 완벽 차단
- **🛡️ 첫 턴 한방제외 모드**: 첫 턴부터 게임이 바로 끝나는 것을 방지하고 랠리를 유도하는 옵션 제공
- **엄격한 5대 티어 분류**:
  - 💥 **1순위 (즉시 승리 한방)**: 상대의 다음 가능한 어휘 수가 정확히 0개(Out-degree = 0)인 1수 필승 단어 (예: `다래쨤`, `새벽녘`, `리튬`)
  - 🎯 **2순위 (한방 유도/외통수)**: 상대의 다음 선택지를 1~30개로 극도로 제한하여 다음 턴에 100% 카운터로 승리하는 함정 공격 단어 (예: `그릇`, `로켓`, `산기슭`, `알루미늄`)
  - 🔥 **3순위 (치명적 압박)**: 상대 반격 단어가 31~100개로 좁혀져 상대방을 질식시키는 포위 단어
  - 🛡️ **4순위 (안전 방어 및 랠리)**: 상대에게 한방 및 유도 역공을 전혀 허용하지 않는 무결점 수
  - ⚠️ **5순위 (위기 탈출 차선책)**: 상대에게 1순위 한방 역공이나 유도 공격을 허용할 위험이 있으나 위기를 넘기는 차선책 수 (예: `다다르다` ➔ 상대가 `다래쨤`으로 반격 가능)
- **단어 복사(Clipboard Copy)** 및 **배틀 즉시 투입** 원클릭 지원
- 네이버 국어사전 공식 실시간 뜻풀이 및 네이버 사전 바로가기 링크 제공

### 2. ⚔️ 실시간 끝말잇기 배틀 (PvE Battle Arena)
- 마스터 AI와 직접 턴을 주고받는 인터랙티브 대결 모드
- 4단계 난이도:
  - 💀 **헬(Hell)**: 1순위 즉시 승리 한방 단어 우선, 100% 무자비한 인공지능
  - ⚡ **어려움(Hard)**: 2수 앞 외통수 및 치명타 공격
  - ⚖️ **중간(Normal)**: 안전 수 우선, 균형 잡힌 랠리
  - 🌱 **쉬움(Easy)**: 플레이어가 편안하게 이어갈 수 있는 안전한 수 위주
- 끄글 54.8만 단어 전수 및 실시간 네이버 국어사전 검증:
  - 미등재 단어, 중복 단어, 잘못된 연결, 두음법칙 자동 판정
- 콤보 카운터, 체인 히스토리, Web Audio API 효과음(타격음, 승리 팡파레)

### 3. 🔍 단어 사전 (Word Dictionary Inspector)
- 끄글 548,502개 단어 및 네이버 국어사전 실시간 검색
- 표제어, 품사, 네이버 국어사전 공인 뜻풀이
- **끝말잇기 전략 지표** 분석:
  - 해당 글자의 후속 단어 개수(Out-degree)
  - 1순위 한방, 2순위 유도, 3순위 압박, 4순위 안전 여부
  - 두음법칙 정방향 변환 분기

## 🛠️ 기술 아키텍처

- **백엔드**: Node.js 고속 서버 (`local-server.js`)
  - 끄글 548,502개 공인 단어 메모리 인덱싱 (로드 시간: ~1.3초)
  - 실시간 네이버 국어사전 공식 API3 비동기 병렬 동기화 & LRU 캐싱
  - 유향 그래프 기반 Out-degree 및 Minimax 5단계 수읽기 엔진
  - 국립국어원 표준 한글 맞춤법 제10~11항 정방향 두음법칙 알고리즘
- **프론트엔드**:
  - 네온 사이버 HUD 다크 테마 디자인 (`style.css`)
  - 반응형 듀얼 패널 레이아웃 (배틀, AI브리핑, 단어 사전)
  - Web Audio API 사운드 시스템 (`sound.js`)
  - 실시간 SPA 인터랙션 및 상태 관리 (`app.js`)

## 🏃 실행 방법

### 방법 1: 런처 더블 클릭
`start.bat` 파일을 더블 클릭하면 자동으로 로컬 서버가 실행되고 브라우저가 열립니다.

### 방법 2: 명령줄 실행
```bash
node local-server.js
```
실행 후 웹 브라우저에서 `http://127.0.0.1:3000`에 접속합니다.
