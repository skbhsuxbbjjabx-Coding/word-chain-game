# 끝잇 v0.2

깔끔하고 편안한 분위기의 온라인 끝말잇기 게임 프로토타입입니다.

## 현재 포함된 기능

- 닉네임 저장이 가능한 로비
- 2인, 3인, 4인 실제 대기열 기반 빠른 매칭
- 친구 초대 코드 생성과 코드 입력 화면
- 채팅형 게임 화면과 20초 턴 타이머, 하트 2개
- 매칭 중 다른 조작 잠금과 매칭 종료
- 서버 사전 검증 엔드포인트, 중복 단어 차단
- 첫 턴 한방단어 차단
- 쉬움/보통/어려움으로 확장 가능한 AI 선택 로직
- 매 판 랜덤 시작 단어를 모든 플레이어에게 동기화
- 확장된 내장 단어 데이터와 어려움 AI의 4수 탐색, 카운터 후보 수 기반 단어 선택
- 사전 뜻을 함께 보여주는 팩트체크 UI
- 소리, 닉네임, 도움말, 게임 룰, 방 코드 복사
- 모바일 입력창, 세로형 플레이어 목록, 터치 영역 대응

## 실행

```bash
npm run dev
```

실행 후 `http://127.0.0.1:4173`을 엽니다.

## Vercel 배포

Vercel은 `vercel.json`에서 Framework를 정적 프로젝트(Other)로 고정하고, `api/` 아래의 명시적 서버리스 함수들을 실행합니다. API 로직은 `api-handler.js`, 공통 Vercel 어댑터는 `api/_handler.js`, 로컬 정적 파일 서버는 `local-server.js`로 분리되어 있습니다. 단어 판정은 외부 사전 API를 호출하지 않고 앱에 내장된 정적 단어 목록으로 처리합니다.

현재 빠른 매칭은 같은 서버에 접속한 실제 플레이어가 정원만큼 모일 때 시작하며, AI로 빈 자리를 채우지 않습니다. 게임 단어 이벤트도 서버를 통해 전달됩니다.

단어 데이터는 직접 정리해 코드에 포함한 정적 목록입니다. 현재 약 1,000개의 한국어 단어와 뜻을 내장하고 있으며, 목록에 없는 문자열은 입력으로 인정하지 않습니다. 따라서 단어 입력 때문에 외부 API 비용이나 호출이 발생하지 않습니다.

AI 모드는 빠른 매칭과 분리되어 있으며, 내장 단어 목록 전체를 대상으로 카운터 후보 수를 계산하고 여러 수 앞까지 탐색해 단어를 고릅니다. 빠른 매칭과 친구 방의 서버 통신은 실제 플레이어 연결과 방 상태 동기화에만 사용됩니다.
