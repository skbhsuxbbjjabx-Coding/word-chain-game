# 끝잇

깔끔하고 편안한 분위기의 온라인 끝말잇기 게임 프로토타입입니다.

## 현재 포함된 기능

- 닉네임 저장이 가능한 로비
- 2인, 3인, 4인 실제 대기열 기반 빠른 매칭
- 친구 초대 코드 생성과 코드 입력 화면
- 채팅형 게임 화면과 20초 턴 타이머
- 서버 사전 검증 엔드포인트, 중복 단어 차단
- 첫 턴 한방단어 차단
- 쉬움/보통/어려움으로 확장 가능한 AI 선택 로직
- 매 판 랜덤 시작 단어를 모든 플레이어에게 동기화
- 어려움 AI의 3수 탐색과 카운터 후보 수 기반 단어 선택
- 사전 뜻을 함께 보여주는 팩트체크 UI
- 소리, 닉네임, 도움말, 게임 룰, 방 코드 복사
- 모바일 입력창, 세로형 플레이어 목록, 터치 영역 대응

## 실행

```bash
npm run dev
```

실행 후 `http://127.0.0.1:4173`을 엽니다.

## Vercel 배포

Vercel은 `vercel.json`에서 Framework를 정적 프로젝트(Other)로 고정하고, `api/` 아래의 명시적 서버리스 함수들을 실행합니다. API 로직은 `api-handler.js`, 공통 Vercel 어댑터는 `api/_handler.js`, 로컬 정적 파일 서버는 `local-server.js`로 분리되어 있습니다. Vercel 프로젝트의 Environment Variables에 `KDICT_API_KEY`를 추가하면 공식 사전 검증도 활성화됩니다.

현재 빠른 매칭은 같은 서버에 접속한 실제 플레이어가 정원만큼 모일 때 시작하며, AI로 빈 자리를 채우지 않습니다. 게임 단어 이벤트도 서버를 통해 전달됩니다.

네이버 사전 API는 공식 공지에 따라 종료되어 직접 사용할 수 없습니다. 따라서 서버는 키를 발급받은 국립국어원 한국어기초사전 Open API를 사용하도록 준비했습니다. 실행 전에 `KDICT_API_KEY` 환경 변수를 설정하면 단어 입력마다 공식 사전 확인을 수행합니다. 키가 없을 때는 내장 샘플 단어만 허용하고, 확인 완료로 표시하지 않습니다.

AI 모드는 빠른 매칭과 분리되어 있으며, `WORD_BANK`를 기반으로 카운터 후보 수가 적은 단어를 고릅니다. 전체 공식 사전 목록을 AI 후보로 쓰려면 API 키와 함께 사전 데이터 동기화 작업이 필요합니다.
